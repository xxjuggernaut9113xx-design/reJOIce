# Input and newer metric integration

These mappings come from retained newer-build bytecode. They are static evidence,
not observations from running the shipping executable.

`UI_Manager.ExecuteUbergraph_UI_Manager` opens the requested media at offset
8286 and continues through 8322, 6884 and 7220 into outcome resolution. The earlier
reconstruction omitted that continuation. The recovered route now checks objective
6's deadline, the edge-card failure branch, the already-finished guard, and the
permission flag before dispatching the existing success or failure outcome.
Enter enters at 17756, jumps to 8413 and shares the media/Tribute route at 8182.
The newer E input enters at 3472 and invokes the edge path outside Music mode.

Objective 7 branches at 8182 to `MilkingEvent` at 8249 and returns instead of
opening the ordinary media/outcome path. The manager event enters at 83023 and
jumps to 79493. It increments metric 36 unless Deal With The Devil is active on
a card other than type 3. Offsets 79695–79850 compare the resulting count with
the Tribute requirement. The reconstructed Tower uses a per-round baseline for
its accumulated session counters.

Metric 45 has a source quirk. Music failure enters through the GameModeSelection
case at 99151, then 98346, 97752 and 98341. Offset 33972 disables item use before
the check at 33886; consequently offset 33910 records metric 45 on every Music
failure along this path. The recovered handler preserves that ordering's result;
it does not invent a narrower test based on the metric's display name.

`CockHero.Recovery.ModeActorIntegration` checks live delegate delivery, Tribute
eligibility, the Music failure counter, real user outcome routing, and duplicate
success suppression. A passing result must be established by a fresh automation
run after compilation; the presence of this contract does not assert that result.
